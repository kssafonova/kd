# Локальный запуск сайта на macOS

## Что понадобится

- Node.js 22.13 или новее: https://nodejs.org/
- Терминал macOS

## Запуск

1. Распакуйте ZIP-архив.
2. Откройте Терминал.
3. Перетащите распакованную папку в окно Терминала после команды `cd ` и нажмите Enter.
4. Установите зависимости:

   ```bash
   npm install
   ```

5. Запустите сайт:

   ```bash
   npm run dev
   ```

6. Откройте адрес, который появится в Терминале. Обычно это:

   ```text
   http://localhost:5173
   ```

Остановить сайт можно сочетанием клавиш `Control + C` в Терминале.

## Где находится основной код

- `app/page.tsx` — страницы, контент и интерактивные сценарии.
- `app/globals.css` — стили desktop и mobile.
- `public/images/` — изображения сайта.
- `app/layout.tsx` — метаданные и общий каркас.

Папка `node_modules` намеренно не включена в архив: она автоматически создаётся после `npm install`.
